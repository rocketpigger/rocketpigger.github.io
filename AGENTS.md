# Homepage maintenance

Use [README.md](README.md) to locate the source for each page and its attachments. Update the source branch. GitHub Actions generates the published `gh-pages` branch.

Before committing, format with the repository’s Prettier setup and build the site with Docker Compose. Check the homepage, news, publications, portrait, dark mode and attachment links. Keep the paper, slide and poster filenames consistent with the BibTeX entries.
